# GhostMark

[English](../README.md) · [خطة العمل](roadmap.md) · [لوحة المشروع](https://github.com/users/Lord-shaban/projects/11)

أداة سطح مكتب مكتوبة بـRust، هدفها التحكم في ظهور علامة تفعيل ويندوز مع إمكانية استرجاع السلوك الأصلي.

## الحالة الحالية

المشروع في مرحلة تجهيز تجربة الجدوى. يوجد فاحص للقراءة فقط يجمع معلومات محدودة عن البيئة؛ لا يوجد تطبيق سطح مكتب جاهز أو إصدار للتحميل، ولم يتم إثبات الإخفاء على أي إصدار ويندوز حتى الآن. نجاح اختبارات الفحص لا يعني أن إزالة العلامة تعمل.

نستهدف Windows 11 x64 أولًا. دعم كل رقم Build يحتاج تجربة موثقة للإخفاء والاسترجاع؛ ولا نعتبر إخفاء علامة النسخة التجريبية دليلًا على إخفاء علامة التفعيل.

## التقنية

- Rust المستقر، بإصدار compiler محدد في المستودع.
- مكتبة Microsoft `windows` لقراءة معلومات البيئة دون تعديل النظام.
- `egui` و`eframe` للواجهة، بعد اجتياز مرحلة المحرك.
- Cargo للبناء والاختبارات، وGitHub Actions للتحقق.
- ترخيص MIT.

الهيكل الحالي يحتوي مكتبة core وفاحص JSON صغيرًا. شغّله بالأمر `cargo run -p ghostmark-probe -- inspect`. الفاحص لا يخفي العلامة، ولا يقرأ مفاتيح المنتج أو حالة التفعيل، ولا ينفّذ أوامر تعديل. راجع [تفاصيله](probe.md) و[بروتوكول التجربة المعزولة](verification/FEASIBILITY-PROTOCOL.md).

## سير العمل

1. تجهيز المستودع والخطة.
2. إثبات الجدوى والإخفاء والاسترجاع داخل جهاز افتراضي معزول.
3. بناء المحرك ومعالجة الفشل والاسترجاع.
4. بناء واجهة سطح المكتب واختبار إمكانية الوصول.
5. اختبار التوافق وقياس الأداء والعمل دون اتصال.
6. إصدار تجريبي موثق، ثم قرار الإصدار الأول.
